# Django CRM System

## Описание проекта

Django CRM System — это веб-приложение для управления клиентской базой и рекламными кампаниями.

Проект позволяет:

- управлять услугами;
- создавать и редактировать рекламные кампании;
- вести учет потенциальных клиентов (лидов);
- создавать контракты;
- переводить лидов в активных клиентов;
- просматривать статистику рекламных кампаний.

## Модели

### Service

Модель услуг.

Поля:

- name — название услуги;
- description — описание;
- price — стоимость.

---

### AdvertisingCampaign

Модель рекламных кампаний.

Поля:

- name — название кампании;
- service — рекламируемая услуга;
- channel — канал продвижения;
- budget — бюджет кампании.

---

### Lead

Модель потенциальных клиентов.

Поля:

- full_name — ФИО;
- phone — телефон;
- email — электронная почта;
- campaign — рекламная кампания.

---

### Contract

Модель контрактов.

Поля:

- name — название контракта;
- service — услуга;
- document — файл контракта;
- signed_at — дата заключения;
- valid_until — дата окончания;
- amount — сумма контракта.

---

### Customer

Модель активных клиентов.

Поля:

- lead — связанный лид;
- contract — связанный контракт.

## Статистика рекламных кампаний

Для каждой рекламной кампании рассчитываются:

- количество лидов;
- количество активных клиентов;
- суммарный доход;
- прибыль.

Прибыль рассчитывается по формуле:

```text
Прибыль = Доход - Бюджет рекламной кампании
```

## База данных

В качестве базы данных используется PostgreSQL 18.

Параметры подключения:

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'crm_db',
        'USER': 'postgres',
        'PASSWORD': '********',
        'HOST': 'localhost',
        'PORT': '5433',
    }
}
```

Для подключения используется пакет:

```text
psycopg2-binary
```
